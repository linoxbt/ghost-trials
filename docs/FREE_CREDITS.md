# Claim the advertised free Token Factory credits

Official resources: https://nebiusglobalaihackathon.devpost.com/resources

1. Open the hackathon's linked promo form: https://nebius.com/promo-code?utm_promo_activation_code=NEBIUS-DEVPOST-GLOBAL26&utm_promo_code_type=Token_Factory&utm_promo_event_code=2026-devpost-global-ai-hack
2. Complete the form with your own details. Confirm the activation code is `NEBIUS-DEVPOST-GLOBAL26`. The hackathon advertises $25 Token Factory credits for this offer.
3. Follow the confirmation/redemption instructions you receive; check spam if necessary. Do not assume credits are available until they appear in your account.
4. Visit https://dev.nebius.com/builders and choose Join the program. The program is free. Sign up, describe Ghost Trials, verify your email, and claim the Token Factory offer. The hackathon advertises another $25 through this route. Offers remain subject to eligibility and terms.
5. In your Token Factory account, check the credited balance, expiration, applicable services, and any billing requirements. If redemption requests a payment you do not want to make, stop and ask the hackathon support team before enabling paid billing.
6. Create a Token Factory API key in your account. Store it privately as `NEBIUS_API_KEY` in the project's `.env`, never in chat or frontend assets. Select an NVIDIA model ID actually available in your account; example model IDs are not proof of availability.

These offers are Token Factory inference credits, not guaranteed GPU VM rental/training credits. They are different from an AI Cloud card deposit. No credits have been claimed and no paid infrastructure has been provisioned by these instructions.

For GPU support, use the Discord linked from the official resources or contact the hackathon organizers. Suggested message:

> I'm building Ghost Trials for the Physical AI track: a G1 robot-policy simulation evaluation tool with NVIDIA models and Nebius inference. The full simulation needs GPU compute and a compatible G1 checkpoint. Are AI Cloud/Serverless GPU credits or a supported evaluation checkpoint available to participants? I have a limited budget and want to validate one end-to-end trial before scaling.

Describe the project for the Builders form:

> Ghost Trials helps robotics engineers find and inspect policy failures before deployment. It evaluates bounded hazards in simulation, compares policy runs, and produces evidence-linked reports with Nemotron on Nebius Token Factory. The current CPU development mode is explicitly synthetic; GPU execution is the next validation milestone.
