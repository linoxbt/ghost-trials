02 / FROM CANDIDATE TO EVIDENCE

One Hunt lifecycle.
Two execution domains.

Search, execution, deterministic verification, and interpretation are distinct stages.

01DEFINE

Set the target.

Choose a controller or supported reference agent, its task, and bounded test budget.

target → search space
02EXECUTE

Run the candidate.

Execute physics or the controlled agent harness and retain state or tool-call events.

candidate → trace
03VERIFY

Check the evidence.

Apply measured task rules or versioned agent assertions. Provider errors are not target failures.

trace → outcome
04REPLAY

Test the next version.

Reproduce a saved Ghost Case and compare a compatible candidate on that case.

case → regression
CPU MuJoCo and bundled reference-agent Hunts execute locally. Agent tools are in-memory mocks; arbitrary external software is blocked. G1/SONIC GPU execution remains unverified, and the humanoid visual above is an illustration. See supported scope ↗
